
1. 객체지향 mcfunction의 특징

1. use storage as a heap space -> 스토리지를 힙 공간으로써 사용한다.

다음과 같은 형태로 스토리지를 구성.

minecraft:space <- resources:{
    stack:[]
    heap:[
        {id : ?, },
        {id : ?, },
        {id : ?, }
    ]  
}

heap의 정보를 찾기 위한 방법
data modify storage minecraft:sapce stack[0] from storage minecraft:space resources.heap[{id:$(id)}]
-> 다음의 연산으로 O(1)연산이 가능.
-> stack[n]의 경우 정적으로 컴파일 시 정해짐.

id : 스코어보드로도 저장이 가능한 4바이트 정수 (signed도 관계 없음.)
-> 포인터의 역할을 할 수 있음.
-> 일단 더하는 방식으로 진행.
